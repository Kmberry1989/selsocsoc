# Main menu editable placeholders

These SVG files are the artwork layer for the title menu. Edit them in Figma,
Illustrator, Inkscape, or any text editor while keeping the filenames stable.

- `background.svg` — full-screen backdrop; design at 1600 × 900.
- `logo.svg` — title/logo area; design at 720 × 260.
- `town.svg` — Enter Cyclical City button artwork.
- `solo.svg` — Solo Practice button artwork.
- `family.svg` — Play Together button artwork.
- `board.svg` — Snug Board button artwork.
- `options-frame.svg` — decorative frame around the selectable option dock;
  design at 760 × 120 and keep the center transparent enough for buttons.

The game supplies accessible button names and click behavior separately, so text
inside these SVGs is decorative. Preserve each SVG's `viewBox`; artwork can be
replaced freely within it.
