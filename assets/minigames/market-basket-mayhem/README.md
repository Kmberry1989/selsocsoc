# Market Basket Mayhem

Featured free-for-all collection game. Players follow a changing three-item
shopping list, collect only the requested goods, and return to checkout.
Incorrect items cost time; town-player difficulty changes response time and
scoring consistency through the shared minigame and Snug Board systems.

The current first pass uses the shared deterministic challenge contract and
existing marketplace prop fallbacks so it remains playable offline. Bespoke
market stalls, basket models, and item icons can replace those fallbacks
without changing the game definition.
