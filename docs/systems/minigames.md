# Minigames Catalog

**Status:** SHIPPED

## What it is

The shared minigame catalog: 24 minigames in the generated manifest, plus Market Basket Mayhem (wired through the shared challenge contract). Minigames run in three contexts: room multiplayer rounds, Solo Practice, and Snug Board everyone-plays rounds.

## The catalog (24 in `assets/minigames/manifest.json`)

coin-scramble, plaza-tag, room-quiz, balloon-pop, plaza-sprint, pond-fishing, hot-potato, hide-and-seek, musical-statues, memory-match, pattern-parade, draw-and-guess, cat-herding, bridge-builders, coin-curling, emote-charades, sneaky-snug, scavenger-snap, dodge-puffs, freeze-tag, treasure-dig, snowball-toss, lantern-hunt, petal-catch — plus **market-basket-mayhem** (see `market-basket-mayhem.md`).

## How it works for the player

- **Room rounds:** the Play button rolls one shared round for everyone in the room. The rotation includes Coin Scramble, Plaza Tag, Room Quiz, Tumble Tiles, Four in a Row, and Noughts & Crosses.
- **Solo Practice:** the Practice tab runs Coin Scramble, Plaza Tag, and Room Quiz without waiting for another player — still real backend rounds with validated scoring.
- **Snug Board:** everyone-plays timing challenges between movement rounds with ranked coin payouts.
- Many activities share a challenge overlay; a few have bespoke implementations. Cards are flat 2D sprites with 3D flip animations.

## Key code files

- `assets/minigames/` — one folder per minigame; `manifest.json` regenerated by `assets/minigames/generate-manifest.mjs` during `npm run build`.
- `assets/minigame-stages.js` + `assets/minigame-stages.css` — staged minigame presentation (dedicated table views, full-screen staging).
- `assets/minigame-expansion.css` — shared challenge-overlay styling.
- `assets/multiplayer.js` — room round orchestration and the shared challenge contract.

## Where state lives

- RTDB `minigames/{roomId}/events` — append-only: dice rolls, pickups, tags, quiz answers, tile eliminations, board moves, reward claims. The client requests only the latest 50 events per room. Rules validate events and reject reward claims until the round has ended.
- Winnings fold into the Firestore player save (`players/{uid}`); no second currency store.

## NPCs involved

- **Chip Chance** — minigame host (dice roll, hypes games, announces winners).

## Known limitations

Per docs/PARTY_NIGHT_AUDIT.md, breadth is high but shared-overlay games don't all meet the bar of distinct polished games yet; eight games are slated for bespoke arenas and input teaching. Minigame exit paths and complete play/finish timing were not destructively exercised (GAMEPLAY-AUDIT.md).
