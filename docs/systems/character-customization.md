# Character Customization

**Status:** SHIPPED

## What it is

Full avatar customization: selfie face, hairstyles, outfits, accessories, tints — with an instant fit-review step before anything enters the Style menu.

## How it works for the player

- **Avatar:** flat coin-disc head with the player's selfie face edge-to-edge, hover/bob animation, spherical hands, flat-bottomed body, wedge feet. Wide skin-tone options, body-mass and height sliders; outfits auto-scale and always overlay the model.
- **Cosmetics** are dev-authored Draco `.glb` files dropped into auto-discovered folders; filenames become catalogue labels (`yellow_raincoat.glb` → "Yellow Raincoat"). Display names come from filenames.
- **Slots:** hairstyles, head accessories, outfits (one whole piece — tunics/ponchos/capes/tabards/wraps, no sleeves or pant legs, to fit peg-shaped bodies), hand accessories, shoes, face-wear, facial hair, held-items, back-items, neckwear.
- **Tinting:** each equipped item stores its own color; players pick a tint or reset to white. The runtime multiplies the tint over the original materials, preserving authored detail. Meshes/materials with `NoTint`/`Untinted` in the name (or glTF extras `snugTint: false`) are excluded.
- **Fit review:** every accessory GLB gets an instant fit preview on the avatar with plain-language notes, manual rotate/scale/move on all three axes, and an approve button. Unapproved pieces stay hidden from the Style menu; fit tweaks save to Firestore.
- **Outfit textures:** 2D outfit textures are supported (`assets/outfit-textures.js`) — outfits are moving toward 2D textures, with 3D kept for hats, held items, and accessories where silhouette matters.

## Key code files

- `assets/cosmetics/` — the auto-discovered catalog folders + `manifest.json` (regenerated by `scripts/generate-cosmetics-manifest.mjs` during `npm run build`); `assets/cosmetics/README.md` is the full authoring guide.
- `assets/fit-review.js` + `assets/fit-review.css` — fit preview, notes, transforms, approval.
- `assets/cosmetic-tints.js` + `assets/cosmetic-tints.css` — tinting system.
- `assets/outfit-textures.js` + `assets/outfit-textures.css` — 2D outfit textures.
- `assets/snug-avatar-template.glb` — sizing reference.

## Where state lives

- Firestore `players/{uid}` — equipped outfit, tints, customization.
- Firestore `gameConfig/fitReviews` — shared fit-review data (public read; writes locked to the dev account).

## NPCs involved

None — though NPCs share a recognizable facial style distinct from players, so players read as foreigners/guests in the NPCs' world (see `npcs.md`).

## Authoring constraints (from README)

Export GLB in meters with embedded textures, under 25k triangles and 2 MB. Origins: coin-head center for hairstyles/head accessories, body center for outfits, one hand/foot center for hand/foot accessories (mirrored both sides). The loader auto-corrects Z-up/Y-up mismatches.
